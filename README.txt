Perry AI Hub Pro
================

How to publish on GitHub Pages
1. Extract this ZIP on your device.
2. Open your GitHub repository (for example, perry-ai-hub).
3. Choose Add file > Upload files.
4. Upload index.html from this ZIP (do not upload the ZIP itself).
5. Commit changes.
6. Open Settings > Pages.
7. Set Build and deployment to Deploy from a branch, branch main, folder /(root), then Save.
8. Wait a few minutes and open https://YOUR-USERNAME.github.io/perry-ai-hub/

Features:
- Searchable AI tool directory and categories
- Favourite tools saved in the current browser using localStorage
- AI image prompt builder (prompt creation only; actual generation uses linked services)
- Basic browser photo editor with brightness, contrast, saturation and download
- Responsive mobile layout

Important:
- External AI tools may require sign-in, payment, credits or have usage restrictions.
- This static site does not itself provide AI chat/image/video generation models.
- Never publish API keys or passwords in a public repository.
